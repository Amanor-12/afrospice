# AfroSpice

AfroSpice is an owner-first retail operations workspace that brings executive reporting, inventory control, checkout, refunds, supplier oversight, customer intelligence, staff management, and a grounded business assistant into one product surface.

## Validation

- `npm.cmd --prefix frontend run lint`
- `npm.cmd --prefix frontend run build`
- `python -m pytest backend/tests/ml_engine -q`
